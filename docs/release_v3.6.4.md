# v3.6.4 更新公告

本次为重要体验优化与缺陷修复版本：全面修复卡片可视化编辑器（GUI）打开时未即时加载已配置信息与派生实体绑定的问题，增强户号精准识别与防重复添加机制，并在前端常驻展示派生实体绑定状态，提供更加顺畅开箱即用的配置体验。

## 更新内容

- **修复卡片编辑器打开即时加载与识别**：彻底解决打开卡片配置面板时，已配置的标准实体与派生实体呈现空白、必须手动点击“展开高级映射”才识别的初始化生命周期时序问题，打开即刻完整呈现全部配置与绑定状态。
- **派生实体自动关联与状态常驻可视**：填入或一键导入标准实体后，缴费记录、停电公告、在线状态实体全自动关联匹配；核心实体下方常驻展示 `[✓ 缴费已绑定] [✓ 公告已绑定] [✓ 在线已绑定]` 指示灯，绑定情况一目了然。
- **增强户号识别比对与防重复机制**：顶部快捷填充栏支持“实体 ID + 10~16位户号 (consNo)”双维度比对，不受实体命名后缀差异影响，精准识别已添加账户并标明 `✓ 户号 xxxx (已添加)`，防止重复导入。
- **优化初始默认配置选择逻辑**：修复向导初始化（`getStubConfig`）的实体探测逻辑，增加子传感器排除规则，杜绝误将“实时电费”、“缴费记录”等子实体选为主实体。
- **前端资源自动刷新（v4.1.4）**：升级 Lovelace 注册资源版本号至 `4.1.4`，集成启动时自动同步注册并刷新浏览器缓存，保障最新卡片逻辑无感生效。

## 升级说明

1. 升级集成后，请重启 Home Assistant 或在「设置 → 设备与服务 → 集成」中重载 **Shaobor electricity** 集成。
2. 建议按 **Ctrl + F5**（Mac 快捷键为 **Cmd + Shift + R**）强制刷新浏览器，以加载最新的前端卡片资源。
3. 现有卡片与实体完全向前兼容，无需重建配置。
