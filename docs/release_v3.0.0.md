# v3.0.0 升级公告（2026-09-21）

本次为大版本升级：**新增手机 App（iOS 链路）数据源**，数据获取方式从网页版单链路扩展为双链路架构。

## 核心变更

### 1. 新增数据源：手机 App（iOS 链路）
- 走国网手机 App 协议（SM4-ECB + SM2 skey 信封 + SM3 签名），经中转后端访问，协议密钥与设备指纹全部由后端持有，不进入 HA。
- 首次登录需短信验证码（设备指纹进入信任名单后可用账号密码登录），登录会话真值存 HA 本地数据库，后端不落库。
- 返回数据与网页版同构：日用电量、月账单、账户余额、电表列表、缴费记录、停电公告等传感器全部支持。

### 2. 数据源热切换（数据库驱动）
- 数据源由后端 `system_settings` 表单条配置 `upstream_source`（web / mobile）决定，所有前端统一服从。
- 在任一集成条目的「选项 → 数据源切换」中切换，写入数据库后下一轮刷新自动热切换，**无需重载 HA 或重配条目**。

### 3. 配置流程体验优化
- **添加条目直达户号选择**：对齐网页版自动检测逻辑——授权码校验通过后，已登录（本地会话有效）直接进入户号选择页，无需重复登录。
- mobile 源不再被残留的网页会话劫持，不会再误建网页版条目。

### 4. 修复
- 户号选择列表显示原始加密 ID → 改为显示短户号（`consNo_dst`），已添加的户号追加「（已添加）」标记。
- mobile 源业务查询全 0：account 字段名两套体系（网页版 `proNo/consSortCode` vs iOS `proCode/consType/consNoSrc`）未对齐导致信封 `target` 为空 → 已同时携带两套字段名。

## 升级说明

- **网页版用户**：无需任何操作，升级后行为与 2.3.6 一致。
- **切换到手机源**：选项 → 数据源切换 → 手机 App → 首次需短信验证码登录。
- 一个 HA 配置项对应一个 machineId = 一个账号；同一账号多户号请用「添加条目」分别添加（列表会标记已添加户号）。
- 手机源要求中转后端已部署 iOS 链路（`/api/mobile/ios/call`、`/api/mobile/ios/profile`）。
